No surveyed encroachment dataset exists for this catchment. Without one there is
nothing to score against, and any accuracy percentage quoted for this tool would
be invented.

What can be and has been measured is agreement: whether an independent spectral
method reproduces the reference this pipeline depends on, on held-out ground.
That is a weaker claim than accuracy and it is the strongest claim the available
data supports. Asked how accurate this is, the honest answer names that
distinction rather than filling the gap with a number.
